# Matteo's System Repair

## Easy Download

For the easiest way to get the program, open the latest **Release** and download `Matteos-System-Repair.bat` from **Assets**.

No installation is required. Simply download the file and run it. Windows will request Administrator privileges when the program starts.

**Version 1.0.0**

Matteo's System Repair is a Windows system repair and health check utility that provides an easy-to-use menu for running built-in Windows diagnostic and repair tools.

## Features

- Check disk health with CHKDSK
- Repair file system errors with CHKDSK
- Scan and repair Windows system files with SFC
- Check the Windows component store with DISM
- Perform a deeper Windows image scan
- Repair Windows image corruption
- Run a full repair sequence
- Automatically requests Administrator privileges

## Requirements

- Windows 10 or Windows 11
- Administrator privileges

## How to Use

1. Download `Matteos-System-Repair.bat`
2. Double-click the file to run it.
3. Allow Administrator access when prompted.
4. Select an option from the menu.
5. Follow the instructions displayed by the program.

## Important

Some repair operations can make changes to Windows or require a restart.

Save your work before performing repairs.

This utility uses built-in Microsoft Windows tools including CHKDSK, SFC, and DISM.
